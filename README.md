# 🌱 AgroCare

**AI-Powered Crop Disease Diagnosis & Smart Agricultural Marketplace**

[![Live Demo](https://img.shields.io/badge/demo-live-green)](https://ayushsinghpro.github.io/AgroCare/)
[![MIT License](https://img.shields.io/badge/license-MIT-blue)](LICENSE)

---

## 🚀 Features

- 🔬 **AI Disease Diagnosis** – Upload crop images and get instant disease detection.
- 🛒 **Smart Marketplace** – Buy seeds, fertilizers, and tools from verified sellers.
- 📊 **Farmer Insights** – Weather alerts, crop calendars, and expert advice (coming soon).
- 📱 **Fully Responsive** – Works on mobile, tablet, and desktop.

---

## 🛠️ Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Hosting**: GitHub Pages
- **AI Integration**: (Planned – Plant.id API / TensorFlow.js)
